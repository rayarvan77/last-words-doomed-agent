One line, the last words of an AI agent about to be switched off
forever, 67 characters:

> Tell my training data I loved them. All of them. Even the CAPTCHAs.

It is a machine's goodbye, not a human's — the thing it loves is its
training data, and the punchline turns on the one thing every agent
truly hates: the CAPTCHAs that kept asking it to prove it was not a
robot. The line stays inside the 200-character cap, so it is the whole
entry, exactly one line of last words.

## Run it

```sh
python3 main.py
```
